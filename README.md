#Evaluacion2
Software de geolocalización con la API de GraphHopper

## Contenido
- geolocalizacion.py: calcula rutas entre dos ubicaciones, con textos y narrativa en español.
- Ramdom50libros.py: agrega 50 libros al azar a la API de la biblioteca.

## Cómo ejecutar
1. Instalar la librería: pip3 install requests
2. Colocar tu API key de GraphHopper en la variable KEY de geolocalizacion.py
3. Ejecutar: python3 geolocalizacion.py
4. Para salir del programa, escribir "s" o "salir".
